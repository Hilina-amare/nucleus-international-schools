# Nucleus International Schools

A modern, high-performance web experience for **Nucleus International Schools** in Addis Ababa, Ethiopia. Delivering the Cambridge International Curriculum from Early Years (Age 2) through Grade 8.

## Features

- **Cambridge Curriculum Showcase**: Interactive roadmap detailing stages from Early Years to Lower Secondary.
- **Interactive Experience & Facilities Carousel**: Dynamic tabbed pillars, campus facilities carousel, and campus life highlights.
- **Dual-Language Polish**: English immersion with Amharic bilingual touches.
- **Admissions & Fee Estimator**: Tuition and enrollment information with interactive booking modals.
- **Modern Responsive Design**: Built with semantic HTML, vanilla CSS design tokens, and modular JavaScript.

## Tech Stack

- **HTML5 & CSS3** (Vanilla CSS with design system tokens)
- **Vanilla JavaScript** (ES Modules)
- **Vite** (Next-generation frontend tooling)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Installation & Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
